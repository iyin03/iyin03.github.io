# iyin03.github.io

Iris Yin's portfolio. Static HTML/CSS built by one Python script (standard library only).
Design rationale is in [DESIGN.md](DESIGN.md).

## Pages

| Address | Page |
| --- | --- |
| `/` | One-screen landing: name, brush column, fog, resume and links |
| `/work/`, `/projects/` | Project lists |
| `/work/<slug>/`, `/projects/<slug>/` | Project pages |
| `/about/`, `/resume/`, `/contact/` | One section each; Resume shows the PDF inline on desktop |

## Art

- The home page hero shows an ink-wash iris painting generated by `tools/make_iris.py` (seeded, so it repaints identically) into `static/img/art/iris.webp`. Its composition follows one of Iris's own iris paintings, which is not published on the site.
- Each section page shows a public-domain (CC0) Chinese ink painting from the Cleveland Museum of Art, set in [content/art.json](content/art.json) with its artist, title, date and museum link. The painting is a background layer, fixed to the bottom-right corner and fading into the paper; its credit is in the page footer.
- To add or swap a painting, run `python tools/make_art.py <scan> <name> [left top right bottom]`. It crops the mounting, whitens the paper so only ink remains, and writes `static/img/art/<name>.webp`. Then point the page's entry in `art.json` at it.

## Preview locally

```bash
python build.py
python -m http.server 4321 --directory dist
```

Then open http://localhost:4321. `python build.py --drafts` also builds projects marked `"draft": true`.

## Add or edit a project

Everything lives in [content/projects.json](content/projects.json). The Work and Projects pages list entries in the order of that file. Each project:

| Field | What it's for |
|---|---|
| `slug` | URL: `/<section>/<slug>/`, e.g. `/projects/fetoscope/` |
| `section` | `"work"` (jobs, research) or `"projects"` (personal, class, hackathon) |
| `title`, `org`, `kind`, `dates` | Shown in the margin of the Work list |
| `outcome` | The headline. Lead with the result, ideally a number |
| `summary` | One plain sentence: what it is |
| `role`, `methods`, `stack` | Short lists, shown under the summary |
| `sections` | Detail page: `[{ "heading": "...", "paragraphs": ["..."] }]` |
| `sections[].figures` | Optional images under a section: `[{ "src": "/img/...", "width": 1200, "height": 600, "alt": "...", "caption": "..." }]`, with the image files in `static/img/` |
| `website` | Optional, shown in the project page details: `{ "label": "psdn.ai", "url": "https://..." }` |
| `links` | Detail page: `[{ "label": "Source on GitHub", "url": "..." }]` |
| `draft` | `true` hides it from the live site |

Your bio, email, links and skills are in [content/site.json](content/site.json). To update your resume, replace `static/Iris_Yin_Resume.pdf` and change `resume_updated` in site.json.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds and publishes to GitHub Pages.
One-time setup: in the repo's Settings → Pages, set Source to "GitHub Actions".

## Motion

- The hero name is written on load by `src/write.js`, which is inlined into the home page.
- `static/motion.js`: Lenis smooth scrolling on GSAP's ticker (1.1s exponential ease; touch stays native), ScrollTrigger brushing on each page's section marker, and the fog.
- `static/site.js` holds behavior that runs even with reduced motion: the Copy email button.
- The hero's ink-wash fog is Vanta's FOG effect, also started in `static/motion.js`. It loads three.js only after the name is written, only on screens 60rem or wider, and never with reduced motion or data saver. Tune its colors and speed in the `VANTA.FOG({...})` call; strength is `.ink-fog.is-on { opacity }` in `src/styles.css`.
- Libraries are pinned copies in `static/vendor/`: Lenis 1.3.26, GSAP 3.15.0 with ScrollTrigger, three.js r134 and Vanta 0.5.24 (fog). To upgrade, replace those files.
- The section paintings carry their own transparency and fade (baked by `tools/make_art.py`), so the fixed layer needs no blend mode or mask. Keep it that way: a blended fixed layer forces a full repaint on every scroll frame.
- Everything respects `prefers-reduced-motion`.

## One-off tools

- `tools/make_paper.py` regenerates the paper texture (needs numpy and Pillow).
- `tools/make_og.py` regenerates `static/og.png`, the 1200×630 link-preview image (needs Pillow and the font files).
- `tools/extract_glyphs.py` regenerates the brush glyphs for the hero from the Ma Shan Zheng font file (needs fontTools). The hand-traced stroke order for the write-on animation is in `tools/strokes.json`.
